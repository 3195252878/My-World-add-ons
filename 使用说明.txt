我的世界小工具 · 使用说明
========================================

【运行】
双击「我的世界小工具-增强版.exe」即可，绿色单文件，无需安装，需要 Windows 10 / 11（64位）。
生成的指令需要在游戏中开启作弊（局域网开放带作弊 / 单人 /give 权限 / 服务器 OP）才能使用。

【新版界面】
· 打开后进入「总览」。左侧按用途分组，顶部切换版本、目标、置顶和浅色／深色主题。
· 生成指令时，宽窗口在右侧显示可编辑的指令输出；窄窗口自动把输出移到底部。
· 使用增强版前请先关闭旧版。两版沿用同一位置的本机设置；旧版不认识收藏、
  世界方案和历史版本等新增字段。若需要回退，先从增强版导出一份 JSON。

【基本用法】
· 顶部选择游戏版本（1.20.1 / 1.21.1）和指令目标（自己 / 最近的玩家 / 全部玩家）。
· 顶部「置顶」可以把窗口钉在最前面，玩游戏时随时查；「浅色主题」／「深色主题」可以切换配色。

【各页面】
· 无限元件：勾选物品后批量生成指令；直接点物品名即生成并复制。
  （1.21.1 需要任意物品的无限元件时，模组切换到 Cell⁴）
  预设共 15 个分类、399 种物品，同一个物品只出现一次（红石粉在「矿物/宝石」、
  下界之星和蜘蛛眼在「生物掉落」、西瓜在「农作物」，搜关键词都能搜到）。
  显示的名字用游戏内官方中文名，和自己游戏里看到的一致。
  预设里每个物品 ID 都对着官方注册表核过，两个版本各查一遍：
  比如「海龟鳞甲」在 1.21.1 出 minecraft:turtle_scute，切到 1.20.1 会自动
  换成当时的 minecraft:scute（1.21.1 已把这条拆成犰狳鳞甲 / 海龟鳞甲两支）。
· 物品ID查询：搜索物品中文名（含原版全量 1300+ 条）。点「扫描」前先填入
  整合包的 mods 目录，可以把模组物品和模组生物的中文名也收进搜索库。
  每条结果可「复制 ID」，也可点「用于…」跳到无限元件、批量生成、物品命名或 255 附魔，自动填好物品 ID。
  搜索库只收真物品：语言文件里那些方块名、旧 ID、组件名（banner.base.black
  之类）都按两版官方注册表筛掉了，不会再搜出点一下就失效的条目。
· 255附魔：勾选附魔、自定义等级（1~255）、套用预设（如一刀999）。
  生成的是 /give 摆好的物品，附魔挂在新版的 enchantments 组件 / 旧版的
  Enchantments 标签上，版本会自动切换写法。
· 手持附魔：不重新发物品，直接给手上这件加附魔（/enchant），
  外加 1.21.1 才支持的「无耐久消耗」（1.20.1 下这个开关会变灰）。
· 物品命名 / 药水（药水·喷溅·滞留·药水箭）/ 刷怪蛋 / 属性 / 头颅：
  填写后生成对应 give 指令。
· 全套装备：选材料和部件，一次生成整身装备。附魔按每条的**原版上限**给
  （锋利 5 级、经验修补 1 级、保护 4 级……），不是一律 255，这样在游戏里
  不会因为超上限被当成无效等级。
· 自定义实体：生成 Boss——名称、大小、血量、攻击、数量、全套下界合金装备，
  以及 NoAI（静止）/ 无敌 / 防消失 / 发光 / 静音 开关；「生物库」可搜索
  整合包里的模组生物。
· 盔甲架：名称、显示手臂 / 无底座 / 隐形 / 小型 / 无敌，外加 7 种姿势预设
  （挥手、坐姿、战斗、奔跑等）。
· 快捷指令：可逐条复制，也可「收藏到首页」，首页收藏使用最新的预设参数。
  「常用指令」可改经验等级（默认 10 亿级）和治疗对象（默认 Xian_Yu12138）；
  「模组与距离」可改距离（默认 15 格）。1.21.1 有方块和实体两条，1.20.1 方块距离需要 Forge。
  AE2、时间之瓶等命令只有安装了对应模组才能使用。自定义指令和传送点仍会自动保存。
· 「快捷指令 → 世界方案」：可保存多套命名方案，也能逐条复制或导出为 .mcfunction。
  默认方案包含死亡不掉落、困难难度、切到白天并锁定、切到晴天并锁定。
  清除所有掉落物仍是单独的快捷指令，不包含在方案内。
· 指令历史：最近 200 条记录。新生成的指令会记录所用版本，旧历史和未指定版本的自定义指令显示「版本未知」。
  导出时先选择顶部游戏版本，再勾选对应的历史；另一版本或版本未知的记录仍可复制，但不能混入导出。
  指令输出区显示生成版本；切换版本后请重新生成或切回原版本，才可复制、导出旧结果。
  「清空历史」之前会保存最近一次恢复快照，保存失败不会清空。
· 批量生成：一个物品给 N 个。

【导出数据包】
在历史页勾选同版本的指令后点「导出所选数据包」，或从无限元件页点「导出数据包」：会在本目录生成一个完整数据包
文件夹（含 pack.mcmeta），把它整个复制到存档的 datapacks 文件夹里，游戏内
执行 /function mc_tool:<函数名> 即可。
函数目录名会自动跟着版本走：
· 1.20.1 → data/mc_tool/functions/
· 1.21.1 → data/mc_tool/function/
（Minecraft 1.21 起把数据包的注册目录全部改成了单数，两个版本之间没有
兼容别名，目录名写错游戏会直接忽略，看不到任何报错。）
1.20.1 和 1.21.1 的 pack_format（15 / 48）也会自动区分。
同名数据包已存在时会自动加 _1、_2 后缀，不会覆盖上一次的导出。

【数据、备份和恢复】
· 日常设置存在 HKEY_CURRENT_USER\Software\minecraft_tool，无需手动保存。
· 「设置与清理 → JSON 配置备份」：留空会导出到程序目录，填写完整文件路径可另存。
  导出不会覆盖已有文件。迁移时填写备份文件路径，先点「预览导入」，再确认替换。
  JSON 包含设置、历史、传送点、自定义指令、收藏和世界方案；不包含三个本机备份槽。
· 「恢复默认配置（保留备份）」会清空当前设置和记录，但保留三个备份槽，
  并保存一个操作前快照。误操作后可点同页的「恢复操作前快照」，不用手动编辑注册表。
  自动快照只保存最近一次，后续的导入、恢复或记录清理可能替换它。需要长期保留请导出 JSON。
· 「彻底清除本机数据」会删除本机配置、三个备份槽及恢复快照，必须输入「彻底清除」确认。
  已导出的 JSON 文件不受影响。若只是想重置某个页面，用「各页输入框恢复默认」。
· 三个本机备份槽支持保存、恢复、清空。恢复、清空和覆盖已有备份时会要求确认。
· 模组扫描结果只存在内存。换整合包后，在「物品 ID 查询 → 模组物品库」重新填路径并扫描。
